Hướng dẫn thay đổi thông tin của cơ sở khám, chữa bệnh vào postman
Bước 1: Import file postman khung mà mỗi CSKCB được cấp vào Postman.
Bước 2: Vào project, rồi chọn Varibles để thay đổi lại thông tin tài khoản CSKCB của mình được cấp.
Lưu ý: Trong phần Varibles người dùng sẽ cần thay đổi các trường thông tin CSKCB của mình bao gồm như: “ username, password, sender-id, msg-id,..”. Bao gồm cả cặp Private key và Public key. Để lấy được cặp Private key và Public key này người dùng cần login tài khoản quản trị của CSKCB mình trên trang admin của hệ thống EMRHUB rồi click vào mục Thông tin cá nhân trên thanh navigation.
Phần thông tin cá nhân này có hiển thị cặp Public key và Private key của CSKCB, người dùng chỉ cần copy lại rồi thay lại vào phần Varibles trên postman là xong.
Hướng sử dụng api 
Bước 1: Call API Login để lấy token phục vụ cho việc call API liên thông (tài khoản của các CSKCB sẽ được cấp bởi SYT và gửi qua gmail kích hoạt).
Trường hợp 1: Nếu call API thành công hệ thống sẽ trả về status code là 200 kèm theo repsonse mô tả dưới đây.
Trường hợp 2: Nếu call API thành công hệ thống sẽ trả về status code là 400 kèm theo repsonse mô tả dưới đây (lúc này người dùng cần check lại thông tin tài khoản liên thông của mình xem đã đúng chưa).
